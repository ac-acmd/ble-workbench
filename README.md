# BLE Workbench

> 🚧 **Status: Early Development** — Core features are actively being built. Follow along or star the repo for updates!

A native **iOS (SwiftUI)** and **Android (Jetpack Compose)** Bluetooth Low Energy (BLE) debugging, packet-testing, and GATT API documentation suite.

## Planned Features
- **Multi-Peripheral Support:** Connect to single or multiple BLE peripherals simultaneously.
- **Custom & Batched Packets:** Send individual custom packets or run serialized and unserialized command batches.
- **Live Packet Inspection & Logs:** View incoming peripheral responses in real time and export full session logs.
- **GATT API Workflows:** Import GATT API documentation to load saved commands, or export your custom packet batches as shareable GATT API docs.

## Tech Stack
- **iOS:** Swift, SwiftUI, CoreBluetooth
- **Android:** Kotlin, Jetpack Compose, Android BLE APIs
